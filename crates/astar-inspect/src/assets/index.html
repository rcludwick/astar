Using an AllScan UCI150 / CM108-class USB interface? Set its rear PTT DEST switch to CTS (not COS). In the COS position, keying the radio fires the chip's “Volume Down” HID and the OS turns your output volume down on every PTT. The client doesn't use the COS line, so CTS is safe.
